Workspace preferences

Small behaviours that run on their own. Like everything else here, they stay on this device.

Conversation titles

Auto-generate titleNames a new chat after its first answer

After the first answer in a new chat, this model reads your question and that answer, then writes a short 8–10 word title for the chat. It runs only for the first message of a chat — later replies leave the title alone. Chat itself keeps using whichever model you pick in the chat screen.

Developer tools

File managementLet the model create, edit, rename and delete files and folders
Shell commandsLet the model run one-off shell commands in the workspace
Approve each commandShow every proposed shell command for your Approve/Deny tap before it runs

File tools stay inside this project folder and can never touch .git, .env or database files; deletions are permanent. Shell is unsandboxed — a command runs as this device's own user, exactly as if you typed it in Termux. Turn it on only if you accept that risk; commands that mention database files are still refused. With Approve each command on, nothing runs until you tap Approve — the safest way to use shell.

System prompt

Added to every message you send, in every chat. Use it for standing instructions — how to answer, what to always include, what to avoid. Leave it empty to use the built-in instructions only.
