Plugins

Extend the workspace

Plugins are MCP (Model Context Protocol) servers. Add one from the list below, connect it, and its tools become available to the assistant — no configuration files, no code. Everything the assistant can do with a plugin comes from that server's own tool list.

MCP is a protocol, not a login. A server still needs its own credential: for GitHub that is a personal access token, or the local server's own browser sign-in where nothing is stored here.

GitHub

MCP SERVER · CONNECT

Sent as Authorization: Bearer to the MCP server, or as GITHUB_PERSONAL_ACCESS_TOKEN for the local server. Leave it empty for the local server's own browser sign-in. Scope it to repo, read:org, and user. It is stored on this device and never shown again.

Comma-separated. repos and users are needed for the account and repository list. Fewer toolsets means a smaller tool list for the model.
