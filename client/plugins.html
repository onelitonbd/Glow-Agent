Extend the workspace

Plugins are MCP (Model Context Protocol) servers. Connect one and its tools appear for the assistant automatically — no code in Glow Agent. The GitHub MCP server lets the AI read, edit, create, rename, and delete files, open issues and pull requests, and commit — all directly on GitHub, with your approval before anything is written.

MCP is a protocol, not a login. GitHub's own MCP server still needs a credential: a personal access token, or the local server's own browser sign-in where nothing is stored here.
