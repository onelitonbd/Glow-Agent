Extend the workspace

Plugins are MCP (Model Context Protocol) servers. Add one from the list below, answer its own setup questions, and its tools become available to the assistant — no configuration files, no code.

Each server asks only for what it needs, and several need nothing at all. MCP is a protocol, not a login, so a server that acts on your account brings its own credential — for GitHub that is a personal access token, or the local server's own browser sign-in where nothing is stored here.
